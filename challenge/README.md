# Fix My Code Challenge

Each file below starts from the supplied challenge implementation and fixes its reported defect.

- `0-fizzbuzz.py`: recognizes multiples of both three and five before single divisors.
- `1-print_square.js`: parses the size in base 10 and prints exactly that many columns and rows.
- `2-sort.rb`: inserts each valid integer at its ascending sort position.
- `3-user.py`: stores and compares the password hash consistently.
- `4-delete_dnodeint/`: unlinks a selected doubly linked-list node before freeing it.
